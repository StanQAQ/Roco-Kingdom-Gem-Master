# 洛克王国：魔法宝石

一个使用 Python 实现的四人策略桌游原型。玩家通过获取属性灵碎、购买宠物和积累永久折扣构建资源引擎，并可触发水、火、草、萌、恶五种属性专精效果。

## 运行环境

- Python 3.11 或更高版本
- 图形界面使用 Qt 6，需要安装 PySide6
- 命令行模式不需要第三方依赖；Qt6 图形界面需要 PySide6

在项目根目录中确认 Python 版本：

```bash
python3 --version
python3 -c "import PySide6; print('PySide6', PySide6.__version__)"
```

## 启动图形界面

推荐使用图形界面进行人机对战：

```bash
python3 -m src.cli --gui
```

首次使用先安装 Qt6 依赖：

```bash
python3 -m pip install PySide6
```

图形界面未传入种子参数时会直接生成随机种子，无需在终端选择。

## 打包为 Windows 单文件程序

在 Windows 电脑上安装 64 位 Python 3.12，并确保安装 Python Launcher。然后双击项目根目录的 `build_windows_exe.bat`。打包完成后，可直接分发并双击运行：

```text
dist/MagicGems.exe
```

生成的单文件程序会直接打开图形界面，不要求玩家另外安装 Python、PySide6 或复制 `media` 资源目录。首次打包需要联网下载构建依赖。也可以将项目推送到 GitHub 后，在 Actions 中手动运行 `Build Windows EXE` 工作流，下载 `MagicGems-Windows-x64` 构建产物。

指定随机种子，便于重现同一组初始市场：

```bash
python3 -m src.cli --gui --seed 42
```

也可以显式指定随机种子：

```bash
python3 -m src.cli --gui --random-seed
```

随机模式会在终端、GUI 顶部和对局日志中显示本局实际种子。之后使用 `--seed 数值` 即可复现该局的初始牌序。GUI 内的“重新开始”会继续使用当前种子。

任一玩家达到 18 分后立即结束并结算胜者；若公共市场全部耗尽，则在本轮结束时结算。

开局从10张魔法师卡中随机公开3张，其余进入牌堆。玩家回合操作结束、且该回合专精效果全部结算后，只检查当前公开卡的条件；双属性宠物同时计入两种属性，预购宠物和资源不计入。获得的卡加3分并由牌堆补位；刚补入的卡从下一次回合结算起才参与检查。一次检查满足多张公开卡时会全部获得，并在 Qt 界面播放逐张出现的金色卡牌动画。

图形界面中：

1. 游戏窗口固定为 1200×800，右侧操作面板宽度固定且不可拖动调整。
2. 公共市场按 3、2、1 级自上而下排列，卡槽位置固定，补入的新卡占据刚空出的槽位；所有卡牌采用 3:4 竖版比例。
3. 点击卡牌选中，再点同一张取消；选中一张时，点击其他卡牌不会切换选择。
4. 右侧先显示资源选择规则和本回合已选资源，再显示公共资源按钮。重复点击同一属性两次，或点击三种不同属性各一次，再点“确认”领取；同属性资源池需至少剩4枚。“确认”也用于购买选中的卡牌，“取消”用于清除当前资源或卡牌选择；“预购”单独保留。
5. 左侧市场和下方区域高度约按 7:3 分配；下方玩家状态、行动记录、预购卡牌区宽度按 3:3:1 分配，预购区可纵向容纳三张不重叠的竖版卡。右侧栏上方依次显示当前购买力（各属性资源加折扣）、已有资源和已购买卡牌；行动与公共资源区固定在右侧栏下方。
6. 已购买卡牌保留完整卡面并缩小显示，在属性列边框内纵向重叠堆叠，每张卡露出顶部的属性与分数。双属性宠物带金色发光边缘，玩家回合内可拖到其任一属性列吸附，之后该属性作为折扣；购买时不再弹出折扣选择框。
7. AI 获得的属性专精由 AI 自动选择目标并结算；玩家自己的属性专精仍由玩家选择。专精记录以“【效果名称】玩家触发了属性专精阶段，效果结果”的自然语言描述，使用粗体和对应属性色；行动记录最新操作置顶。

## 启动命令行游戏

玩家对战三名 AI：

```bash
python3 -m src.cli
```

使用固定随机种子：

```bash
python3 -m src.cli --seed 42
```

命令行会显示市场、资源、分数和可用操作。属性输入使用中文字符：`水`、`火`、`草`、`萌`、`恶`。

## 四 AI 自动对战

在终端中快速运行一局：

```bash
python3 -m src.cli --ai-battle --random-seed --interval 0
```

以 0.5 秒的行动间隔观察对局：

```bash
python3 -m src.cli --ai-battle --seed 1 --interval 0.5
```

在图形界面中观察四 AI 对战：

```bash
python3 -m src.cli --gui --ai-battle --random-seed --interval 0.5
```

`--interval` 不能小于 0。如果不传入该参数，程序会在启动时询问行动间隔。

## 自动平衡测试

使用项目根目录下的 `simulate_balance.py` 批量运行四 AI 对局。每轮测试的数据单独保存在子目录中，种子段连续且互不重叠；批次目录会生成汇总报告和 JSON 索引：

```bash
python3 simulate_balance.py --runs 3 --games 10000 --seed-start 1
```

以上命令运行 3 轮、每轮 10,000 局，种子分别为 `1–10000`、`10001–20000`、`20001–30000`。输出默认写入 `analysis/` 下带时间戳的批次目录。每轮子目录包含逐局与逐玩家数据、资源统计、汇总 JSON 和报告；批次根目录的 `batch_report.md` 与 `batch_summary.json` 汇总各轮结果。

常用参数：

```bash
python3 simulate_balance.py --runs 5 --games 2000 --seed-start 50000 --output analysis/my_batch --progress-every 100
```

省略 `--runs` 或设为 `1` 时仍是单轮模式，保持原有用法。`--output` 在多轮模式下指定批次根目录；已有且非空的目录不会被覆盖。

## 命令行参数

```bash
python3 -m src.cli --help
```

| 参数 | 用途 |
|---|---|
| `--seed N` | 使用指定的固定种子 |
| `--random-seed` | 每次启动时自动生成新种子 |
| `--gui` | 启动 Qt6 图形界面 |
| `--ai-battle` | 启动四 AI 自动对战 |
| `--ai-only` | 直接运行无人操作的命令行对局 |
| `--interval N` | 设置 AI 每次行动的间隔秒数 |

`--seed` 和 `--random-seed` 不能同时使用。图形界面未传种子参数时默认随机；纯命令行模式未传时仍会交互询问开局方式，选择固定种子后直接回车则使用种子 `1`。

## 运行测试

先安装 pytest：

```bash
python3 -m pip install pytest
```

运行全部测试：

```bash
python3 -m pytest -q
```

测试覆盖基础资源规则、购买与预购、游戏结束条件，以及五种属性专精效果。

## 日志

图形界面会为每局对战创建独立日志，保存在：

```text
logs/magic_gems_YYYYMMDD_HHMMSS_microseconds.log
```

日志包含玩家行动、属性专精触发与结算结果，可用于还原问题或进行数值分析。

## 常见问题

### 提示 `No module named src`

请确认终端当前位于项目根目录，也就是包含 `pyproject.toml` 和 `src` 目录的位置。

### 提示 `No module named PySide6`

请在当前 Python 环境安装 Qt6 依赖：

```bash
python3 -m pip install PySide6
```
